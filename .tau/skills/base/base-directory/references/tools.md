# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `base_addresses_create` — Create a shared Directory record in addresses.
- `base_addresses_get` — Read one record from Directory addresses by UID.
- `base_addresses_list` — List Directory addresses with bounded filters and pagination.
- `base_addresses_update` — Edit a shared Directory record in addresses using its version.
- `base_affiliations_create` — Create a shared Directory record in affiliations.
- `base_affiliations_get` — Read one record from Directory affiliations by UID.
- `base_affiliations_list` — List Directory affiliations with bounded filters and pagination.
- `base_affiliations_update` — Edit a shared Directory record in affiliations using its version.
- `base_parties_create` — Create a shared Directory record in parties.
- `base_parties_get` — Read one record from Directory people and organizations by UID.
- `base_parties_list` — List Directory people and organizations with bounded filters and pagination.
- `base_parties_update` — Edit a shared Directory record in parties using its version.
