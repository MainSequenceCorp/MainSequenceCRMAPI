# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `catalog_categories_create` — Create a Catalog record in categories.
- `catalog_categories_get` — Read one record from Catalog categories by UID.
- `catalog_categories_list` — List Catalog categories with bounded filters and pagination.
- `catalog_categories_update` — Edit a Catalog record in categories using its expected version.
- `catalog_items_create` — Create a Catalog record in items.
- `catalog_items_get` — Read one record from Catalog items by UID.
- `catalog_items_list` — List Catalog items with bounded filters and pagination.
- `catalog_items_update` — Edit a Catalog record in items using its expected version.
- `catalog_unit_groups_create` — Create a Catalog record in unit-groups.
- `catalog_unit_groups_get` — Read one record from Catalog unit groups by UID.
- `catalog_unit_groups_list` — List Catalog unit groups with bounded filters and pagination.
- `catalog_unit_groups_update` — Edit a Catalog record in unit-groups using its expected version.
- `catalog_units_convert` — Convert a decimal quantity between active units.
- `catalog_units_create` — Create a Catalog record in units.
- `catalog_units_get` — Read one record from Catalog units by UID.
- `catalog_units_list` — List Catalog units with bounded filters and pagination.
- `catalog_units_update` — Edit a Catalog record in units using its expected version.
