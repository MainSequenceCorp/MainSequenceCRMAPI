# Collaboration Discussions

Resolve the discussion before reading or posting messages. Read or modify only
records the owner returns for this requester. Confirm the exact discussion and
requested message before posting. Use the message UID and expected version for
edits or retractions. Supply the required reason and preserve the distinction
between current text and revision history.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
