# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `collaboration_discussions_archive` — Archive a discussion at its expected version.
- `collaboration_discussions_close` — Close a discussion at its expected version.
- `collaboration_discussions_create` — Open an internal discussion.
- `collaboration_discussions_get` — Read an authorized discussion.
- `collaboration_discussions_list` — Find discussions visible to the requester.
- `collaboration_discussions_reopen` — Reopen a discussion at its expected version.
- `collaboration_discussions_restore` — Restore a discussion at its expected version.
- `collaboration_discussions_update` — Edit a discussion's title and description at its current version.
- `collaboration_messages_edit` — Edit an eligible discussion message at its expected version.
- `collaboration_messages_get` — Read an authorized message.
- `collaboration_messages_list` — Read a bounded page of messages in the specified discussion.
- `collaboration_messages_post` — Post a message in the specified internal discussion.
- `collaboration_messages_retract` — Retract an eligible discussion message with the required reason.
- `collaboration_messages_revisions` — Read permitted revisions of one message.
