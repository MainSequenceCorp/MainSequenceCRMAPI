# Commerce Merchants

Use the merchant site and service offer tools for drafts. Read checkout
details and recorded payment state under the current merchant's permissions.
Only the owner handoff can create an invoice linked to a confirmed order and
checkout. Grant reads show status. Use the merchant screen for publication
and grant controls. Customer checkout stays on its dedicated surface.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
