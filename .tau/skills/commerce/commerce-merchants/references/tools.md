# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `commerce_checkouts_create_invoice` — Create one draft Finance invoice linked to the checkout and confirmed Sales order.
- `commerce_checkouts_get` — Read customer checkout records for one UID.
- `commerce_checkouts_list` — Find customer checkout records.
- `commerce_checkouts_payment_status` — Read the recorded payment state for a checkout.
- `commerce_grants_get` — Read portal access grant status for one UID.
- `commerce_grants_list` — Find portal access grant status.
- `commerce_offers_create` — Create a merchant draft in offers.
- `commerce_offers_get` — Read service offers for one UID.
- `commerce_offers_list` — Find service offers.
- `commerce_offers_update` — Edit the selected draft in offers.
- `commerce_sites_create` — Create a merchant draft in sites.
- `commerce_sites_get` — Read merchant sites for one UID.
- `commerce_sites_list` — Find merchant sites.
- `commerce_sites_update` — Edit the selected draft in sites.
