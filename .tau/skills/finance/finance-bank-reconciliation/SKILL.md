# Finance Bank Reconciliation

Read masked bank accounts and use the selected account UID to find saved
movements. Review the exact movement, counterparty, amount and candidate
invoices with `finance_bank_reconciliation_review`. When a Finance operation
was already attempted, read its outcome by the original request UID. Use
Finance's reconciliation screen to approve and commit the reviewed decision.
Keep provider consent, account mapping and statement import in their
existing screens.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
