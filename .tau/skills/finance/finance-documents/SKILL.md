# Finance Documents

Use bounded searches for invoices and recorded payments. Match exact party,
company, currency, state and UID. Create or edit drafts through the typed
commands. Use `finance_invoices_create_from_sales` for a confirmed order.
The result contains the draft linked to the source order. An allocation needs
two posted documents, matching currency and parties, both expected versions
and a precise decimal amount. Payment records represent externally observed
funds. Use the Finance screen for posting, voiding and allocation reversal.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
