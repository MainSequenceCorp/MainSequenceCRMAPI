# Inventory Stock

Find the stock item policy, location and balance before preparing a movement.
Check company, quantity, unit and exact state. Create a draft, then use the
owner's prepare and complete commands. Use the Sales handoff for an order
delivery. Balance changes come from owner movements. Use Inventory's reviewed
screen for reversals and Finance valuation posting.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
