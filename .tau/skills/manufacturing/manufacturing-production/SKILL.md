# Manufacturing Production

Read the active bill of materials and planned quantities before creating a
production order. Use the production order and step UIDs to start or finish
work. Reserve materials before completing the owner transaction. Check the
returned movement references and inspect authorized valuation. Use the existing
review screen for posting the production valuation to Finance.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
