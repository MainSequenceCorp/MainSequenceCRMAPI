# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `manufacturing_boms_activate` — Activate an eligible bill of materials.
- `manufacturing_boms_archive` — Archive an eligible bill of materials.
- `manufacturing_boms_create` — Create a draft bill of materials.
- `manufacturing_boms_get` — Read one of the bills of materials by UID.
- `manufacturing_boms_list` — Find bills of materials.
- `manufacturing_boms_update` — Edit a draft bill of materials.
- `manufacturing_orders_cancel` — Cancel the order through the existing production and stock transaction.
- `manufacturing_orders_complete` — Complete the order through the existing production and stock transaction.
- `manufacturing_orders_create` — Create a draft production order from an active recipe.
- `manufacturing_orders_get` — Read one of the production orders by UID.
- `manufacturing_orders_list` — Find production orders.
- `manufacturing_orders_reserve` — Reserve the order through the existing production and stock transaction.
- `manufacturing_orders_valuation` — Read Finance valuation for the selected production order.
- `manufacturing_steps_finish` — Finish a specified production step.
- `manufacturing_steps_start` — Start a specified production step.
