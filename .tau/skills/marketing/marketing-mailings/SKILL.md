# Marketing Mailings

Read the current subscriber state and mailing before changing preferences,
adding recipients or editing a draft. Recipient listing is scoped to an exact
mailing UID. Queue, capture and simulation are local tools. Their results do
not mean mail was sent. Use the follow-up link command only when CRM and the
exact eligible task are available. The recipient's consent and suppression
rules continue to apply.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
