# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `marketing_mailings_cancel` — Cancel an eligible mailing at its expected version.
- `marketing_mailings_capture` — Capture a queued mailing in local simulation without delivering mail.
- `marketing_mailings_create` — Create a record in mailings.
- `marketing_mailings_get` — Read one of the mailings by UID.
- `marketing_mailings_list` — Find mailings.
- `marketing_mailings_queue` — Queue the selected mailing for the local capture workflow.
- `marketing_mailings_update` — Edit a draft mailing.
- `marketing_recipients_add` — Add an eligible recipient to the specified draft mailing.
- `marketing_recipients_events` — Read the recipient's recorded mailing events.
- `marketing_recipients_get` — Read one mailing recipient.
- `marketing_recipients_link_followup` — Link an existing eligible CRM follow-up task to the recipient.
- `marketing_recipients_list` — List recipients of the specified mailing.
- `marketing_recipients_remove` — Remove an eligible recipient using the required versions.
- `marketing_recipients_simulate` — Record a local simulated recipient event without contacting the recipient.
- `marketing_subscribers_create` — Create a record in subscribers.
- `marketing_subscribers_get` — Read one of the subscribers by UID.
- `marketing_subscribers_list` — Find subscribers.
- `marketing_subscribers_set_subscription` — Record the subscriber's authorized subscription change.
