# People Workforce

Search departments, employees and absences through their own tools. Return
only the fields the owner provides and the user needs. Confirm the employee,
task UID and versions before staffing. Submit the person's absence request
before an eligible manager approves or rejects it. The owner requires a
different authorized approver and prevents self-approval.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
