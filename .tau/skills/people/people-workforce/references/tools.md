# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `people_absences_approve` — Approve a versioned absence request under the owner's approval rules.
- `people_absences_cancel` — Cancel a versioned absence request under the owner's approval rules.
- `people_absences_create` — Create a record in absences.
- `people_absences_get` — Read one of the permitted absences.
- `people_absences_list` — Find permitted absences.
- `people_absences_reject` — Reject a versioned absence request under the owner's approval rules.
- `people_absences_submit` — Submit a versioned absence request under the owner's approval rules.
- `people_absences_update` — Edit a record in absences using its version.
- `people_departments_archive` — Archive the selected record in departments.
- `people_departments_create` — Create a record in departments.
- `people_departments_get` — Read one of the permitted departments.
- `people_departments_list` — Find permitted departments.
- `people_departments_restore` — Restore the selected record in departments.
- `people_departments_update` — Edit a record in departments using its version.
- `people_employees_archive` — Archive the selected record in employees.
- `people_employees_create` — Create a record in employees.
- `people_employees_get` — Read one of the permitted employees.
- `people_employees_list` — Find permitted employees.
- `people_employees_restore` — Restore the selected record in employees.
- `people_employees_staff_task` — Assign the employee to a project task through the guarded staffing workflow.
- `people_employees_update` — Edit a record in employees using its version.
