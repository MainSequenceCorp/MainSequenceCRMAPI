# Projects Delivery

Resolve projects and tasks by name and then UID. Read versions before edits
and state transitions. Use the time-entry tools with the owning task UID.
Use `projects_projects_create_from_sales` for a confirmed service order
and `projects_projects_bill` for a delivered project. The owner validates
eligible records and creates the linked draft invoice. Read current linked
records before retrying an uncertain handoff.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
