# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `projects_projects_bill` — Create a draft invoice for a delivered project through the owner handoff.
- `projects_projects_cancel` — Cancel a project at its expected version.
- `projects_projects_close` — Close a project at its expected version.
- `projects_projects_create` — Create a record in projects.
- `projects_projects_create_from_sales` — Create a linked project from a confirmed Sales service order.
- `projects_projects_deliver` — Deliver a project at its expected version.
- `projects_projects_get` — Read one of the projects by UID.
- `projects_projects_list` — Find projects.
- `projects_projects_reopen` — Reopen a project at its expected version.
- `projects_projects_start` — Start a project at its expected version.
- `projects_projects_update` — Edit one of the projects at its expected version.
- `projects_tasks_create` — Create a record in project tasks.
- `projects_tasks_get` — Read one of the project tasks by UID.
- `projects_tasks_list` — Find project tasks.
- `projects_tasks_set_state` — Change a project task state using its expected version.
- `projects_tasks_update` — Edit one of the project tasks at its expected version.
- `projects_time_entries_create` — Record time against the specified project task UID.
- `projects_time_entries_get` — Read one recorded time entry.
- `projects_time_entries_list` — List recorded work for a specified project task UID.
- `projects_time_entries_void` — Void an eligible time entry with the required reason and version.
