# Reporting Runs

Read the definition and selected source scope before queuing a run. Read its
state before advancing, retrying or recovering it. The result and row tools
return an authorized snapshot. Verify compares snapshot versions against the
current source. Use smaller pages when the result is too large. Export data
only for the requesting user's authorized workflow.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
