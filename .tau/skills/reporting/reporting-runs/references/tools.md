# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `reporting_definitions_archive` — Archive an eligible saved report definition.
- `reporting_definitions_create` — Create a governed report definition.
- `reporting_definitions_get` — Read one of the report definitions by UID.
- `reporting_definitions_list` — Find report definitions.
- `reporting_definitions_restore` — Restore an eligible saved report definition.
- `reporting_definitions_update` — Edit a report definition at its version.
- `reporting_runs_advance` — Execute one eligible report run through the owner.
- `reporting_runs_cancel` — Cancel an eligible report run.
- `reporting_runs_export` — Read the authorized report run export.
- `reporting_runs_get` — Read one of the saved report runs by UID.
- `reporting_runs_list` — Find saved report runs.
- `reporting_runs_recover` — Recover an eligible report run.
- `reporting_runs_result` — Read the authorized report run result.
- `reporting_runs_retry` — Retry an eligible report run.
- `reporting_runs_rows` — Read the authorized report run rows.
- `reporting_runs_start` — Queue one run of a selected report definition.
- `reporting_runs_verify` — Compare captured results with the current authorized source records.
