# Reporting Schedules

Read schedules and the referenced definition before creating or changing a
schedule. Use the current version and review the interval and resulting run
scope before activation. Creation, editing and activation are advertised only
with a recent local worker heartbeat for the requester. Pause is available
locally so the operator can stop future runs when the worker is unavailable.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
