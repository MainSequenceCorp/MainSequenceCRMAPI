# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `reporting_schedules_activate` — Activate a reviewed schedule against a ready local worker.
- `reporting_schedules_create` — Create a paused report schedule when its local worker is available.
- `reporting_schedules_get` — Read a saved report schedule.
- `reporting_schedules_list` — Find saved report schedules.
- `reporting_schedules_pause` — Pause a local report schedule at its expected version.
- `reporting_schedules_update` — Edit a schedule at its expected version when its local worker is available.
