# Settings Administration

Read the current activation policy with `settings_module_activation_get`.
Use `settings_module_activation_preview` with the complete proposed set and
policy version. Explain any dependencies and affected workflows. Apply the
reviewed change in the administrator's ERP screen. Base configuration tools
operate on exact operating companies, currencies, languages, and number
sequences under the owner's existing configuration capability.

Consult the [tool reference](references/tools.md) and the live MCP schema before calling a tool.
