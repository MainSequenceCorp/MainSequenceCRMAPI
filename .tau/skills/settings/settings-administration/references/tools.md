# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `settings_currencies_create` — Create a Base record in currencies.
- `settings_currencies_get` — Read one Base record in currencies.
- `settings_currencies_list` — Find Base-owned currencies.
- `settings_currencies_update` — Edit a Base record in currencies.
- `settings_languages_create` — Create a Base record in languages.
- `settings_languages_get` — Read one Base record in languages.
- `settings_languages_list` — Find Base-owned languages.
- `settings_languages_update` — Edit a Base record in languages.
- `settings_module_activation_get` — Read the Organization's versioned module activation policy.
- `settings_module_activation_preview` — Review proposed module dependencies and affected features without saving.
- `settings_number_sequences_create` — Create a Base record in number-sequences.
- `settings_number_sequences_get` — Read one Base record in number-sequences.
- `settings_number_sequences_list` — Find Base-owned number-sequences.
- `settings_number_sequences_update` — Edit a Base record in number-sequences.
- `settings_operating_companies_create` — Create a Base record in operating-companies.
- `settings_operating_companies_get` — Read one Base record in operating-companies.
- `settings_operating_companies_list` — Find Base-owned operating-companies.
- `settings_operating_companies_update` — Edit a Base record in operating-companies.
