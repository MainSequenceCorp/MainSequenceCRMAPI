# Available MCP tools

Confirm the exact schema with `erp_tools_describe`. The current catalogue reflects access and module readiness.

- `settings_locale_preferences_get` — Read your own Business Directory language and timezone preferences.
- `settings_locale_preferences_update` — Save your own language and timezone. Use version zero before your first saved record.
- `settings_preferences_get` — Read your ERP menu preferences.
- `settings_preferences_update` — Edit your ERP menu preferences with the expected version.
