# Projects and services API

Projects owns delivery projects, tasks and whole-minute effort. CRM follow-ups
remain independent. Base supplies shared customers, companies and optional people.
Core Projects works with optional Sales/Finance integration disabled.

- [Concepts and rules](concepts.md)
- [API contracts](api.md)
- [Local deployment](delivery.md)

Source review and API ADR are in `engineering/projects`. The companion frontend
owns project/task forms, effort history and user Help inside the existing ERP site.
No new Agent or MCP interface is part of this release. Local verification is in
progress; hosted deployment requires separate explicit approval.
